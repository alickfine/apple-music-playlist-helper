# Apple Music 自然语言通用技能设计

## 目标

把现有 `am-playlist` 本机助手封装为可独立分发的自然语言 Skill。任何符合运行条件的用户都可以用自然语言描述歌曲和目标播放列表，由技能完成目录核对、输入生成、去重、添加和写后复核，无需手写命令行，也不需要 Apple Developer Program、MusicKit 密钥或 Apple Music 账号密码。

技能不预设曲风、语言、年代、用途、商店区域或曲目数量。用户可以处理任意曲风和任意数量的曲目；曲风等推荐条件只在当次请求中提供，未提供时不自动附加“试音”“古典”“人声”等偏好。

“任何人”在本设计中指：拥有受支持 macOS、可正常使用并已登录个人账号的“音乐”App、能够为所用代理宿主授予必要本机权限的用户。技能不共享账号能力；所有添加操作都发生在当前 Mac 的当前“音乐”账号中。

## 非目标

- 不支持仅使用 iPhone、iPad、Windows、Android 或 Apple Music 网页版的环境。
- 不代替用户订阅 Apple Music、登录账号或绕过地区目录限制。
- 不提供远程托管的 Apple Music 写入服务。
- 不删除、移动、重排、下载或分享现有曲目。
- 不根据近似曲名盲目点击，也不使用截图、OCR 或固定坐标。
- 不内置个人播放列表名称、地区、歌曲清单、绝对路径或权限状态。
- 不设置固定曲风、固定推荐数量或曲目数量上限。

## 分发结构

仓库保留开发、测试和说明文件，并产出一个可独立安装的最小技能目录。技能不得让 `SKILL.md` 引用开发者电脑上的固定路径：

```text
skill/apple-music-playlist/
  SKILL.md
  agents/
    openai.yaml
  scripts/
    bootstrap.sh
    invoke.sh
  assets/
    helper/
      Package.swift
      Sources/
```

`SKILL.md` 定义自然语言触发条件和代理工作流；`agents/openai.yaml` 提供技能列表中的名称、简介和默认提示；`assets/helper` 中的 Swift Package 是本机执行层；`bootstrap.sh` 负责首次构建；`invoke.sh` 提供稳定、低令牌的机器入口。安装后的技能目录必须自包含，不依赖仓库的开发文档、测试目录或原始开发路径。

技能不分发预编译二进制。首次使用时在用户本机从随技能提供的源码构建，因此可以适配当前 Mac 架构，并让用户审查实际执行代码。构建产物保留在技能自己的 `.build` 目录，不修改 shell 配置。

## 自然语言交互契约

以下表达都应触发技能：

- “把《被遗忘的时光》加入我的试音播放列表。”
- “找 20 首古典和人声试音曲，放进 Apple Music 的音响测试。”
- “先看看这批歌哪些已经在列表里，不要修改。”
- “把这些 Apple Music 链接加入歌单，添加完播放第一首。”
- “把我列出的 300 首歌加入通勤歌单，分批处理也不要减少数量。”

技能从自然语言中提取：

- 目标播放列表名称；
- 歌曲名称、艺人、Apple Music 链接或目录 ID；
- 用户当次给出的曲风、语言、年代、情绪或用途等推荐条件；
- 用户明确指定的商店区域，以及能否采用默认区域；
- 用户要求的数量，或用户已列出歌曲的实际数量；
- 是否允许创建播放列表；
- 是否只试运行；
- 是否播放首个新增曲目。

缺少播放列表名称时，技能只询问这一项，不猜测用户的私人播放列表。用户已经列出歌曲时，数量就是清单长度；用户要求推荐但未给数量时，询问一次期望数量。没有曲风等推荐条件时，不添加隐含限制，也不为此追问。

商店区域按以下优先级确定：

1. 用户在当前请求中明确指定的区域；
2. Apple Music 链接路径自带的区域；
3. 用户在技能配置中保存的默认区域；
4. 当前 macOS 系统区域所对应的 Apple Music storefront；
5. 以上均不可可靠确定时，再询问用户一次。

技能不得把中国区、美国区或开发者所在区域写成所有用户的固定默认值。来自多个区域的链接混合出现时，应按曲目保留原区域并在写入前报告潜在可用性差异。

## 曲目解析与目录核对

技能接受四类输入：

1. 完整 Apple Music 单曲链接；
2. 目录 ID 加曲名和艺人；
3. 曲名加艺人；
4. 自然语言推荐要求。

对于第 3、4 类，代理必须使用当前可用的 Apple Music 目录连接器或公开 Apple Music 页面进行搜索。写入前每首曲目必须获得：

- 仅含 ASCII 数字的目录 ID；
- 非空曲名；
- 非空艺人；
- `https://music.apple.com` 链接；
- 与目录 ID 完全相同的唯一 `i` 查询参数。

搜索结果必须属于按上述优先级确定的商店区域。无法唯一确认的曲目以“未解析”报告，不得降级为模糊点击。技能不限制请求数量；大量曲目可以在内部划分处理批次，但不得静默截断、抽样或减少用户要求的曲目。

## 执行流程

1. 解析自然语言请求；只补齐播放列表、推荐数量和无法确定的区域等真正阻塞执行的信息。
2. 检查 macOS、“音乐”App、构建工具和技能内部助手。
3. 首次使用时运行 `bootstrap.sh`，只在技能目录构建 Release 可执行文件。
4. 搜索并验证曲目目录信息，生成临时 UTF-8 JSON；临时文件不含账号凭据。
5. 运行只读试运行，读取目标播放列表并计算重复项与计划新增项。
6. 若用户已在当前请求中明确说“直接添加”“确认添加”或等价授权，则继续执行；否则集中展示一次摘要并请求一次确认。
7. 按输入顺序添加，单首失败不阻断后续曲目；大量输入可分批生成临时 JSON，但结果顺序和总数量保持不变。
8. 每次写入后重新读取播放列表，只有复核存在才报告成功。
9. 输出新增、重复、未解析、失败和最终曲目数；用户要求时播放首个新增曲目。
10. 删除技能创建的临时输入文件。

## 权限与隐私

技能只使用当前 Mac 的本机能力：

- “音乐”自动化权限用于读取目标播放列表、创建明确授权的新列表和播放曲目；
- 辅助功能权限用于在“音乐”辅助功能树中按完整目录 ID 和完整播放列表名称执行准确操作；
- 网络访问只用于查询公开 Apple Music 目录页面或已连接的目录工具。

技能不得读取或保存 Apple ID 密码、Cookie、MusicKit 令牌、开发者密钥或付款信息。不得把播放列表完整内容发送到远程服务；去重只在本机处理。诊断默认只包含当前请求涉及的曲目。

## 安全确认规则

- “查看”“检查”“先试运行”“不要修改”始终只执行 `--dry-run`。
- “直接添加”“确认添加”或同义表达视为当前批次的一次写入授权，不重复询问等价确认。
- 普通“加入”“放进”请求先试运行，再集中确认一次新增数量、重复数量、目标播放列表和是否创建。
- `--create`、`--play-first` 只有在自然语言中明确要求时启用。
- 删除、移动、重排、分享和下载不属于该技能能力，即使用户提出也不得由此执行层完成。

## 错误处理

- 缺少 Swift：提供准确的 Xcode Command Line Tools 安装提示，不执行网络下载安装。
- 缺少辅助功能权限：停止在写入前，说明“系统设置”中的中文授权路径。
- 缺少“音乐”自动化权限：报告实际脚本错误和授权位置，不反复触发提示。
- 播放列表不存在：默认停止；仅在明确授权创建时创建一次并复核。
- 曲目地区不可用或目录信息不唯一：逐首报告，不使用其他地区或同名版本替代。
- 无法确定默认区域：集中询问一次，不偷偷使用开发者区域。
- 大量曲目中途失败：保留已完成结果和剩余进度，允许从未完成项继续，不重复添加已复核成功的项目。
- 写后复核失败：标记失败，不声称已添加，也不尝试删除或补偿性修改。

## 用户可见输出

技能跟随用户当前会话语言回复；机器状态保持稳定英文枚举。默认摘要包含：

- 目标账号环境：仅表述为“当前 Mac 的音乐账号”，不输出账号标识；
- 目标播放列表；
- 请求、已新增、已存在、未解析和失败数量；
- 每首非成功项的简短原因；
- 是否播放首个新增曲目。

## 测试与验收

### 技能行为测试

在没有技能指引的基线场景中记录代理是否会：要求用户手写命令、使用个人绝对路径、跳过地区核对、重复索要确认或在“只查看”请求中写入。完成 `SKILL.md` 后使用相同场景复测，必须全部改为规定的自然语言流程。

至少覆盖：

- 首次使用且尚未构建助手；
- 仅给曲名和艺人；
- 给出多个 Apple Music 链接；
- 推荐 20 首并加入指定播放列表；
- 不给曲风时不附加隐含曲风限制；
- 分别指定中国区、美国区和其他有效 storefront；
- 未指定区域时采用用户配置或系统默认区域，无法确定时只询问一次；
- 单首、20 首和超过 100 首输入均不被技能截断；
- 明确只试运行；
- 明确直接添加；
- 播放列表缺失但未授权创建；
- 曲目跨地区不可用；
- 权限不足；
- 同批输入和现有播放列表重复。

### 执行层测试

保留并扩展现有 Swift 自动测试，确保通用化不破坏输入校验、目录 ID 精确匹配、去重、写后复核、中文诊断和 JSON 输出。

### 本机安全验收

使用已存在曲目执行真实 `--dry-run`：预期返回 `skipped_duplicate` 和退出码 `0`，验收前后播放列表曲目数完全一致。实际写入验收只允许针对专用临时播放列表，并需要单独的明确授权；不得用用户的长期播放列表做破坏性测试。

## 完成标准

- 技能目录可由标准技能安装方式复制到其他 macOS 用户环境。
- 全新路径安装后，不引用 `/Users/macmini` 或任何开发者专用位置。
- 用户可以只用自然语言完成试运行和一次确认后的添加。
- 技能不固定曲风、区域或数量，并能按请求、链接、配置或系统区域确定 storefront。
- 首次构建、权限缺失、地区不可用、区域无法确定和列表不存在均有清晰提示。
- 所有自动测试、发布构建和本机只读验收通过。
- 技能包不包含个人数据、密钥、预编译二进制或账号状态。
